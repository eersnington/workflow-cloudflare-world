# Workflow Studio CLI

Scaffold Workflow DevKit apps with one command for supported frameworks

## Quick Start

```bash
# Bun
bunx workflow-studio@latest init

# pnpm
pnpm dlx workflow-studio@latest init

# npm
npx workflow-studio@latest init
```

## What you get

- Framework starters for Next.js, SvelteKit, Nitro, Hono, Nuxt, Express, Vite.
- Minimal workflow trigger, and AI SDK example option across all frameworks.
- Guided env setup for official and community worlds during init.
